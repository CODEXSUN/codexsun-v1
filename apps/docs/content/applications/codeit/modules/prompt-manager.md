# Codeit Prompt Manager Module

Prompt Manager stores prompts and tracks runs sent to a selected Codex chat.

## Workflow and ownership

The workspace lists and edits saved prompts. It also shows prompt runs and approvals.
The API owns prompt storage, run records, and the related routes.
Sending a prompt requires the human's explicit instruction.
