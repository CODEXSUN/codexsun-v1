### 4. Chat

Chat provides real-time team collaboration, direct messaging, topic channels, broadcast channels, file sharing, presence, and optional Telegram synchronization.
Request transport helper: `apps/chat/web/src/modules/chat/chat.services.ts`.
Backend router & access rules: `apps/chat/api/src/modules/chat/chat.routes.ts`, `chat.realtime.ts`, `chat.service.ts`.

| Page key                 | UI workspace                    | User actions                                        | Backend API endpoint & method                                                                                                                                            | Required permission                   | Realtime / socket behavior                                |
| ------------------------ | ------------------------------- | --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------- | --------------------------------------------------------- |
