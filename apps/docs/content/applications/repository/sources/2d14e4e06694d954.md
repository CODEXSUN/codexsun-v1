# Codeit

Codeit is a standalone development workspace in `devkits/codeit`.

Run `npm run dev -w @codexsun/codeit` from the repository root. The app listens on `127.0.0.1:7070` by default. Set `CODEXSUN_CODEIT_WEB_PORT` to choose another port.

The overview and workspace are a UI foundation. Development tools, persistence, and an API are not connected.
