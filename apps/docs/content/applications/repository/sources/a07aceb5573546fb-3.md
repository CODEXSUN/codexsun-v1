## API prefix, alias, and header contract

### URL prefix routing and rewrites

The backend monolith uses Fastify and can be reached directly on its port or through an upstream reverse proxy (Nginx or Vite dev server).

| Request path pattern | Upstream target    | Rewriting rule                                                                                           | Notes                                                                                                                               |
| -------------------- | ------------------ | -------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `/api/app/*`         | Fastify root (`/`) | Fastify `rewriteUrl: resolvePlatformApiUrl` strips `/api/app` prefix.                                    | Used by Platform desktop web.                                                                                                       |
| `/api/platform/*`    | Fastify root (`/`) | Nginx `location ^~ /api/platform/` strips prefix and proxies to root. Vite dev proxy also strips prefix. | Used by Ecommerce services. Direct calls to Fastify port must not use `/api/platform` unless an explicit route alias is registered. |
| `/api/billing/*`     | Fastify root (`/`) | Vite/Nginx proxy strips `/api/billing/` and forwards to `/billing/*`.                                    | Supported proxy alias.                                                                                                              |
| `/api/core/*`        | Fastify root (`/`) | Vite/Nginx proxy strips `/api/core/` and forwards to `/core/*`.                                          | Supported proxy alias.                                                                                                              |
| `/crm/*`             | Fastify direct     | No prefix stripping; registered directly on Fastify router.                                              | Primary canonical route for CRM.                                                                                                    |
| `/billing/*`         | Fastify direct     | No prefix stripping; registered directly on Fastify router.                                              | Primary canonical route for Billing.                                                                                                |
| `/chat/*`            | Fastify direct     | No prefix stripping; registered directly on Fastify router.                                              | Primary canonical route for Chat.                                                                                                   |
| `/ecommerce/*`       | Fastify direct     | Direct routes registered under Fastify.                                                                  | Primary canonical route for Ecommerce.                                                                                              |

### Required session and context headers

For every authenticated mobile request, the native HTTP transport must attach the verified scope headers:

- `x-codexsun-session-slot`: Active session slot token (e.g. hex32), tying request to server-side session slot.
- `x-tenant-id`: UUID of the authenticated tenant.
- `x-tenant-db`: Isolated MySQL database name for the tenant (resolved from session).
- `x-company-id`: Active company ID selected by user (required for Billing documents and financial reports).
- `x-financial-year-id`: Active financial year ID selected by user (required for sequential document numbering).
- `x-billing-report-currency`: 3-letter currency code (e.g. `INR`, `USD`) for Billing report balance conversions.
- `Authorization`: `Bearer <token>` (when bearer mode is negotiated) or native cookie jar containing `__Host-codexsun_session_<slot>`.

### Build environment prerequisites

- **JavaScript / Host**: Node.js 20+, single root `npm` dependency installation, Vite build output to `dist/apps/cxmobile/web`.
- **Android**: Android Studio Jellyfish / Ladybug, Android SDK Build-Tools 34.0.0 / 35.0.0, JDK 17 or 21, Gradle 8.2+.
- **iOS**: macOS Sonoma 14.x or Sequoia 15.x, Xcode 15.x or 16.x, CocoaPods or Swift Package Manager (SPM). Physical iPhone with active Apple Developer signing identity for TestFlight/device distribution.
