## Refinements required for reliable delivery

1. Build a persisted OP vertical slice before expanding every supporting screen.
2. Treat duplicate detection as a review aid. Shared family mobile numbers must remain valid.
3. Record tariff and assignment facts at the visit. Current master edits must not rewrite historical reports.
4. Keep server transition checks, idempotency, optimistic concurrency, and audit inside the same operation boundary.
5. Treat patient block, confidentiality, inactive status, and registration cancellation as separate policies.
6. Test privacy through generic owners as well as hospital screens.
7. Test matrix totals, timezone cutoffs, and active-as-of IP semantics against persisted detail.
8. Add doctor booking UI because schedule configuration alone cannot prove availability or double-booking protection.
9. Add only the admission/discharge controls needed for IP reporting. Do not invent treatment or bed workflows.
10. Audit each increment independently and turn every valid finding into a tracked repair task.
